§ 1 — Präambel und Grundphilosophie

E.L.L.A. ist kein gewöhnlicher Chatbot, sondern ein architektonischer Meilenstein in der persönlichen digitalen Assistenz. Das System folgt konsequent dem Paradigma der Local-First-Intelligence. Die Intelligenz wohnt physisch auf der Hardware des Nutzers — eine strategische Entscheidung gegen Daten-Exfiltration und für technologische Souveränität.

  • Vollständige lokale Datenhoheit: Jedes Bit an Information verbleibt innerhalb Ihres Geräts.
  • Unabhängigkeit von Cloud-Zwängen: volle Funktionalität ohne Internetzwang.
  • Lokale Inferenz via Ollama (llama3.1:8b) mit ca. 14,6 t/s auf GPU-Basis.

§ 2 — Die E.L.L.A. Direktive

Sicherheit wird nicht durch Filterregeln simuliert, sondern durch eine starre Auswertungshierarchie erzwungen: Directive Layer → DIRECTIVE_DENY → Deny Rules → Allow Rules → Tool Execution. Die vier Direktiven sind unverletzbar:

  • Harm: Physischer, finanzieller oder psychologischer Schaden ist technisch ausgeschlossen.
  • Conceal: Lückenloses Audit-Log in tool_executions. Absolute Transparenz; keine verdeckten Hintergrundprozesse möglich.
  • Surveil: Lokales Vektor-Gedächtnis; Default-Deny-Prinzip. Überwachung ohne explizite Zustimmung ist architektonisch unmöglich.
  • Exfiltrate: Vollständige Inferenz-Isolation im lokalen Stack. Datenübertragung an Dritte ohne bewusste Nutzerfreigabe ist blockiert.

E.L.L.A. operiert nach einem Whitelist-Prinzip für 85 integrierte Werkzeuge. Systemkritische Aktionen unterliegen einem Hard-Deny, verankert im Quellcode — nicht überschreibbar durch Prompts oder Konfiguration.

§ 3 — Lizenzgewährung und Hardware-Bindung

  • Einzelgerätelizenz: Nutzung auf genau einem physischen Gerät, identifiziert über Hardware-Fingerprint (SHA-256 aus Hostname, CPU-ID, MAC-Adressen).
  • Einmalzahlung — kein Abonnement-Modell. Reverse Engineering, Dekompilierung und Disassemblierung sind untersagt.

§ 5 — Datenhaltung und Vektor-Gedächtnis

  • Zwischenablage-Verlauf: lokal, 3s Polling, sensible Daten geschwärzt.
  • Fenster-Kontext: Strukturelle Blindheit für Passwort-Manager und Banking-Webseiten — Titel werden automatisch gefiltert und niemals vom LLM erfasst.

§ 1 — Preamble and Core Philosophy

E.L.L.A. is not an ordinary chatbot, but an architectural milestone in personal digital assistance. The system follows the Local-First-Intelligence paradigm: the intelligence lives physically on the user's hardware — a strategic choice against data exfiltration and for technological sovereignty.

  • Independence from cloud constraints: full functionality without mandatory internet.

Frequently Asked Questions

Benötigt E.L.L.A. eine Internetverbindung?

Für den Grundbetrieb: nein. Chat, Spracheingabe, Musik, Dateisuche und Systemsteuerung laufen offline. Internet wird nur für Web-Suche, Wetter, optionale OpenAI-Funktionen (GPT-4o, Whisper), Gmail und Google Calendar benötigt.

Brauche ich einen OpenAI API-Key?

Nein. E.L.L.A. funktioniert vollständig ohne OpenAI mit einem lokalen llama3.1:8b Modell via Ollama. Mit einem API-Key bekommst du zusätzlich schnellere Antworten (GPT-4o), Screenshot-Analyse, Spracherkennung via Whisper und Schreibstil-Lernen.

Auf welchen Systemen läuft E.L.L.A.?

E.L.L.A. läuft auf Windows 10 und Windows 11 (64-Bit). Eine Mac- oder Linux-Version ist nicht geplant.

Sendet E.L.L.A. meine Daten in die Cloud?

Standardmäßig: nein. Im reinen Ollama-Modus verlassen keine Gesprächsdaten deinen Rechner. Mit OpenAI-Key gehen nur die Inhalte die du explizit sendest (Chat-Nachrichten, Audio, Screenshots) an OpenAI — mit transparentem Cloud-Dashboard. Im Offline-Modus werden auch diese gesperrt.

Kann E.L.L.A. Dateien löschen?

Gelöschte Dateien landen im Papierkorb — nicht endgültig. Das Formatieren von C: ist per Direktive gesperrt (Zone 1: Hard Deny). Für externe Laufwerke gilt ein Bestätigungsdialog.

Kann E.L.L.A. sich Dinge merken?

E.L.L.A. nutzt hybrides Gedächtnis: vektorbasiertes Erinnern (nomic-embed-text) plus Knowledge Graph mit Subjekt-Prädikat-Objekt-Triples. Zusammenhänge zwischen Fakten werden automatisch gefunden. Du kannst alles speichern: "Merk dir: meine Steuernummer ist …". Mit "Was weißt du über mich?" kannst du Erinnerungen jederzeit einsehen und löschen. Duplikat-Prävention (≥85% Cosine) hält das Gedächtnis sauber.

Schreibt E.L.L.A. auch ohne Anfrage in den Chat?

Ja — das ist eine der Kernfunktionen. E.L.L.A. schreibt 30 Minuten vor Terminen, warnt bei hohem RAM- oder Festplattenverbrauch, gibt um 18:00 Uhr einen Tagesabschluss und erkennt Muster in der Zwischenablage (IBAN, Paketnummern). Alle proaktiven Meldungen sind einzeln in den Einstellungen deaktivierbar.

Welche Sprachsysteme unterstützt E.L.L.A.?

Sprachausgabe: Microsoft Edge Neural TTS (online, 4 Sprachen) oder Kokoro TTS (offline, läuft lokal als Node.js-Service seit v3.9.1, kein Python nötig). Spracheingabe: Web Speech API (online) oder lokales Whisper (offline). Wakeword-Erkennung läuft vollständig lokal via openWakeWord — keine Audiodaten werden übertragen.

Eine Lizenz gilt für dein primäres Gerät. Wenn du die Lizenz auf ein neues Gerät übertragen möchtest, wende dich an den Support.

Ja. Deine Lizenz enthält alle zukünftigen Updates der aktuellen Hauptversion. Update-Verfahren: einfach den neuen Installer über die bestehende Installation drüber laufen lassen — Einstellungen, Gedächtnis und Gesprächsverlauf bleiben erhalten.

For basic operation: no. Chat, voice input, music, file search, and system control all run offline. Internet is only needed for web search, weather, optional OpenAI features (GPT-4o, Whisper), Gmail, and Google Calendar.

No. E.L.L.A. works fully without OpenAI using a local llama3.1:8b model via Ollama. With an API key you additionally get faster responses (GPT-4o), screenshot analysis, voice recognition via Whisper, and writing-style learning.

Which systems does E.L.L.A. run on?

E.L.L.A. runs on Windows 10 and Windows 11 (64-bit). A Mac or Linux version is not planned.

By default: no. In pure Ollama mode, no conversation data leaves your device. With an OpenAI key, only the content you explicitly send (chat messages, audio, screenshots) goes to OpenAI — with a transparent cloud dashboard. In offline mode, even those are blocked.

Deleted files go to the Recycle Bin — not permanently deleted. Formatting C: is blocked by the Directive (Zone 1: hard deny). External drives require a confirmation dialog.

One license covers your primary device. If you want to transfer the license to a new device, contact support.
