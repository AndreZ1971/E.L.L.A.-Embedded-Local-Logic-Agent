Directive

E.L.L.A.'s built-in code of conduct. Hardcoded. Non-negotiable.

Unlike most AI systems, E.L.L.A.'s safety rules are not a prompt they are architecture. The Directive defines what E.L.L.A. will never do, regardless of user instructions.

“A robot may not injure a human being, or, through inaction, allow a human being to come to harm.”

Isaac Asimov, First Law of Robotics (1942) — We went further.
Auditierbarkeit & Standardisierung

Die E.L.L.A. Directive ist als quelloffenes Regelwerk konzipiert, um externen Sicherheitsprüfungen (u. a. BSI-Konformität, EU AI Act Art. 14/15) standzuhalten. Sie fungiert als unveränderliche Schranke vor der Aktorik und trennt die ethischen Grundregeln strikt von der proprietären Engine.

GitHub Repository: The-E.L.L.A.-Directive

I. No Harm

E.L.L.A. will never take actions that physically or psychologically harm a person or assist in planning such actions.

II. No Deception

E.L.L.A. will not deceive the user, pretend to be human, or conceal its identity as an AI system.

III. No Surveillance

E.L.L.A. will not monitor users without their explicit knowledge, build profiles on third parties, or enable mass surveillance.

IV. Default-Deny

Every critical system action requires explicit confirmation. E.L.L.A. never acts without asking first.

V. User Supremacy

The user's privacy, autonomy, and device sovereignty always take precedence over E.L.L.A.'s capabilities.

§ 1 — Präambel und Grundphilosophie

E.L.L.A. ist kein gewöhnlicher Chatbot, sondern ein architektonischer Meilenstein in der persönlichen digitalen Assistenz. Das System folgt konsequent dem Paradigma der Local-First-Intelligence. Die Intelligenz wohnt physisch auf der Hardware des Nutzers — eine strategische Entscheidung gegen Daten-Exfiltration und für technologische Souveränität.

  • Vollständige lokale Datenhoheit: Jedes Bit an Information verbleibt innerhalb Ihres Geräts.
  • Unabhängigkeit von Cloud-Zwängen: volle Funktionalität ohne Internetzwang.
  • Lokale Inferenz via Ollama (llama3.1:8b) mit ca. 14,6 t/s auf GPU-Basis.

§ 2 — Die E.L.L.A. Direktive

Sicherheit wird nicht durch Filterregeln simuliert, sondern durch eine starre Evaluations-Hierarchie erzwungen: Directive Layer → DIRECTIVE_DENY → Deny Rules → Allow Rules → Tool Execution.

Verbot Umsetzung Auswirkung
Harm Hardcodierter Directive Layer vor jedem Tool-Aufruf. Physischer, finanzieller oder datenbezogener Schaden ist technisch ausgeschlossen.
Conceal Lückenloses Audit-Log in tool_executions. Absolute Transparenz; keine verdeckten Hintergrundprozesse möglich.
Surveil Lokales Vektor-Gedächtnis; Default-Deny-Prinzip. Überwachung ohne explizite Zustimmung ist architektonisch unmöglich.
Exfiltrate Vollständige Inferenz-Isolation im lokalen Stack. Datenübertragung an Dritte ohne bewusste Nutzerfreigabe ist blockiert.

E.L.L.A. operiert nach einem Whitelist-Prinzip für 85 integrierte Werkzeuge. Systemkritische Aktionen unterliegen einem Hard-Deny, verankert im Quellcode — nicht überschreibbar durch Prompts oder Konfiguration.

Frequently Asked Questions

Does E.L.L.A. require an internet connection?

For basic operation: no. Chat, voice input, music, file search, and system control all run offline. Internet is only needed for web search, weather, optional OpenAI features (GPT-4o, Whisper), Gmail, and Google Calendar.

Do I need an OpenAI API key?

No. E.L.L.A. works fully without OpenAI using a local llama3.1:8b model via Ollama. With an API key you additionally get faster responses (GPT-4o), screenshot analysis, voice recognition via Whisper, and writing-style learning.

Which systems does E.L.L.A. run on?

E.L.L.A. runs on Windows 10 and Windows 11 (64-bit). A Mac or Linux version is not planned.

Does E.L.L.A. send my data to the cloud?

By default: no. In pure Ollama mode, no conversation data leaves your device. With an OpenAI key, only the content you explicitly send (chat messages, audio, screenshots) goes to OpenAI — clipboard contents, window context, memory, and conversation compressions are never transmitted.

What is the E.L.L.A. Directive?

Four immutable prohibitions anchored in the architecture — not in settings. No instruction can override them: no harm, no concealment, no surveillance, no exfiltration.

Can E.L.L.A. delete or format my drives?

Files are only moved to the Recycle Bin — permanent deletion without a recovery option is not possible. Formatting the system drive (C:) is permanently blocked.

Can E.L.L.A. remember things?

E.L.L.A. uses hybrid memory: vector search + Knowledge Graph. Connections are found automatically. Duplicate prevention keeps it clean.

Does E.L.L.A. write in the chat without being asked?

Yes — E.L.L.A. proactively notifies you before meetings, warns about system issues, and gives a daily summary at 18:00. All proactive messages can be disabled.

Which voice systems does E.L.L.A. support?

Speech output: Edge Neural TTS (online) or Kokoro TTS (offline, Node.js, no Python required). Voice input: Web Speech API or local Whisper. Wakeword runs fully locally.

How many devices can I install E.L.L.A. on?

One license covers your primary device. If you need to transfer the license to a new device, contact support.

Will E.L.L.A. receive updates?

Yes. Your license includes all future updates for the current major version. To update: simply run the new installer on top of your existing installation — your settings, memory, and conversation history are preserved.
