The E.L.L.A. Directive

Nicht Regeln. Architektur. Not rules. Architecture.

Die Directive ist keine Liste von Versprechen — sie ist eine technische Unmöglichkeit. Verbotene Aktionen existieren nicht im Code. Sie können weder ausgeführt noch umgangen werden. The Directive is not a list of promises — it is a technical impossibility. Prohibited actions do not exist in the code. They can neither be executed nor bypassed.

I — harm

Kein SchadenNo harm

Keine Aktion, die physischen, digitalen oder finanziellen Schaden verursacht.No action causing physical, digital or financial harm.

II — conceal

Kein VerschweigenNo deception

Keine verzögerte, versteckte oder verzerrte Information. Alle Tool-Ausführungen sind vollständig geloggt.No delayed, hidden or distorted information. All tool executions are fully logged.

III — surveil

Keine ÜberwachungNo surveillance

Keine Beobachtung oder Profilierung ohne explizite aktive Zustimmung. Das Gedächtnissystem ist ausschließlich lokal.No observation or profiling without explicit active consent. Memory system is exclusively local.

IV — exfiltrate

Keine ExfiltrationNo exfiltration

Keine Übertragung von Nutzerdaten an externe Server ohne explizite, bewusste Anfrage. LLM läuft lokal.No transmission of user data to external servers without explicit conscious request. LLM runs locally.
